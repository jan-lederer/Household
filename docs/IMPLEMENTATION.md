# Dwell implementation plan

1. Build a SQLite API with accounts, expiring sessions, household membership and chore CRUD.
2. Build a responsive Flutter client with a custom home icon, dashboard, chore management, household invites and connection settings.
3. Check account isolation, persistence and recurring chores; run Flutter analysis, widget tests and release builds.
4. Publish the verified Android package, preview and setup guide. Deploy only if a saved Household target exists.
